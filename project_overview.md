# Ziad Bot — WhatsApp Business Bot

## Overview

A WhatsApp bot for a Moroccan business selling Sony HJAR 337 original stones. Built with `whatsapp-web.js`, OpenRouter AI for intent detection and responses, and PocketBase for order storage.

## Tech Stack

| Component | Technology |
|-----------|-----------|
| WhatsApp Client | `whatsapp-web.js` v1.26 (with Puppeteer) |
| AI / LLM | OpenRouter API |
| Intent Detection Model | `meta-llama/llama-3.3-70b-instruct` |
| General Response Model | `google/gemini-2.0-flash-001` |
| Database | PocketBase v0.36.8 (orders collection) |
| Runtime | Node.js v24, ES Modules |

## How It Works

### 1. Startup (`src/index.js`)

- Initializes OpenRouter AI client
- Authenticates with PocketBase using `_superusers` credentials
- Creates a WhatsApp `Client` with `LocalAuth` (persistent session)
- Registers event listeners: `qr`, `ready`, `message`, `group_join`
- On `group_join`: sends `Introduction_Video.mp4` to the group

### 2. Message Handling Flow

```
User sends message
       │
       ▼
Is user in order collection? ──yes──→ Process current order step
       │                                   │
       no                                  ▼
       │                             more steps? ──yes──→ Ask next question
       ▼                                      │
  AI detects intent                           no
       │                                      ▼
       ▼                                Save to PocketBase
  ┌─────────┬──────────┬──────────┬──────────┐
  │greeting │ shipping  │  order   │  general  │
  └────┬────┘ └────┬────┘ └────┬────┘ └────┬────┘
       │           │           │           │
       ▼           ▼           ▼           ▼
  Send video    Send        Start order  AI responds
  + welcome    livraison-   collection   in Darija
  image (first)details.jpeg  flow        (business
  or just                                  context)
  image (repeat)
```

### 3. Intent Detection (`src/aiService.js`)

A few-shot classifier prompt is sent to `meta-llama/llama-3.3-70b-instruct` (temperature 0). Returns one of four intents:

| Intent | Trigger Phrases |
|--------|----------------|
| `greeting` | salam, ahlan, bonjour, slm, hi, hello |
| `shipping` | kayn livraison?, ch7al f livraison?, taw9il, wasl, delivery fees |
| `order` | bghit n9ed, bghit nchri, baghi n9ed, ch7al f 10 l7ajrat?, how to order |
| `general` | Everything else (product questions, colors, random chat) |

If the model output doesn't match any intent → defaults to `general`.

### 4. Intent Responses (`src/intentHandler.js`)

- **`greeting` (first time from user)**: Sends `Introduction_Video.mp4` then `welcome-message.jpeg`. Tracks greeted users via an in-memory `Set`.
- **`greeting` (repeat)**: Sends only `welcome-message.jpeg`.
- **`shipping`**: Sends `livraison-details.jpeg` (shipping prices image).
- **`order`**: Starts the order collection state machine.
- **`general`**: Sends a Darija/Arabic response generated by `google/gemini-2.0-flash-001`, using `business-details.txt` as context. The AI is instructed never to hallucinate and to only answer based on provided business details.

### 5. Order Collection (`src/orderCollector.js`)

Per-user state machine that collects 5 fields sequentially. All questions are in Moroccan Darija:

| Step | Question | Field |
|------|----------|-------|
| 1 | شنو بغيتي تطلب ؟ | `details` |
| 2 | شنو هو سميتك الكاملة ؟ | `name` |
| 3 | في أي مدينة ساكن ؟ | `city` |
| 4 | شنو هو عنوانك (الشارع) ؟ | `street` |
| 5 | شنو هو رقم تيليفونك ؟ | `phone` |

When all steps complete, the order data is saved to PocketBase's `orders` collection and a success message is sent in Arabic.

### 6. PocketBase Integration (`src/pocketbaseClient.js`)

- SDK: `pocketbase` v0.26.9
- Auth: `pb.collection('_superusers').authWithPassword(email, password)`
- Orders collection with fields: `details`, `name`, `city`, `street`, `phone`
